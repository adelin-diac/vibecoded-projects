# Vibecoded Projects

A monorepo containing multiple independent web projects by Adelin Diac.

## Repository Structure

```
vibecoded-projects/
├── simple-maths-tools/    # Educational math tools for children
└── [future projects]/
```

Each subdirectory is a self-contained project with its own `CLAUDE.md` for project-specific context.

## Working in This Repo

1. **Identify the target project** - Determine which subdirectory the task relates to
2. **Read the project's CLAUDE.md** - Each project has its own tech stack and conventions
3. **Stay within project boundaries** - Only modify files in the relevant project directory
4. **Test from project directory** - Run any tests/builds from within that project's folder

## Code Style

- Clear, descriptive variable names
- Comments only for non-obvious logic
- Small, focused functions
- Consistent formatting within each project

## Commits

- Format: `[project-name] brief description`
- Keep commits focused on a single change
- Reference issue numbers when applicable
